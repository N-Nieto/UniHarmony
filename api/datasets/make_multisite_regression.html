make_multisite_regression#

uniharmony.datasets.make_multisite_regression(n_sites: int = 2, n_samples: int | Sequence[int] = 1000, n_features: int = 10, target_range_per_site: tuple[float, float] | Sequence[tuple[float, float]] | None = None, signal: Mapping[str, float] | None = None, n_informative: int | None = None, noise_strength: float | Sequence[float] = 0.1, site_effect: Mapping[str, float | Sequence[float] | Mapping[str, Any]] | None = None, site_effect_features: int | float | Sequence[int] | None = None, site_effect_heterogeneity: float = 0.0, covariates: Sequence[Covariate | str | Literal['age', 'sex', 'tiv', 'quality']] | None = None, site_names: Sequence | None = None, as_frame: bool = False, return_ground_truth: Literal[False] = False, random_state: int | RandomState | Generator | None = 42) → tuple[Any, Any, Any]#
uniharmony.datasets.make_multisite_regression(n_sites: int = 2, n_samples: int | Sequence[int] = 1000, n_features: int = 10, target_range_per_site: tuple[float, float] | Sequence[tuple[float, float]] | None = None, signal: Mapping[str, float] | None = None, n_informative: int | None = None, noise_strength: float | Sequence[float] = 0.1, site_effect: Mapping[str, float | Sequence[float] | Mapping[str, Any]] | None = None, site_effect_features: int | float | Sequence[int] | None = None, site_effect_heterogeneity: float = 0.0, covariates: Sequence[Covariate | str | Literal['age', 'sex', 'tiv', 'quality']] | None = None, site_names: Sequence | None = None, as_frame: bool = False, *, return_ground_truth: Literal[True], random_state: int | RandomState | Generator | None = 42) → tuple[Any, Any, Any, dict[str, Any]]

Simulate multi-site regression data with signal, covariates, noise and site effects.

The data follow the model:

y = s * f(Signal) + e,  e ~ N(0, 1)
X = SiteEffect(Signal + CovariateEffects + Noise; site)

  1. Base samples (the signal) are drawn from the population of the generator selected by signal, and their target y from them.

  2. Each site keeps the samples whose target falls in its range of the population (target_range_per_site), e.g. a site that recruits children and one that recruits adults: the sites then differ in their target, and therefore in their signal. No sample is used twice.

  3. Optional covariates are drawn per site and their effects, the same in every site, are added to the signal (not to the target).

  4. Independent Gaussian noise is added. Signal, covariate effects and noise form the data without site effect (site_free).

  5. The Effect of Site (EoS) of site_effect is applied. It changes the features only; the target is never affected.

Except for the generator and the target ranges, the parameters and their meaning are those of make_multisite_classification() (without the "class_interaction" site effect, which needs classes).

Units. All strengths (site effects, noise, covariate effects) are in units of the SD of each feature in the population of the signal (1 for "linear", 1 / sqrt(12) for "friedman1").

Parameters:
n_sitesint, optional (default 2)

Number of sites to simulate.

n_samplesint or list of int, optional (default 1000)

If an int, the total number of samples, split as evenly as possible across sites. If a list (or array), the number of samples of each site; every site needs at least 1 sample.

n_featuresint, optional (default 10)

Number of features per sample.

target_range_per_sitetuple, list of tuple or None, optional (default None)

Range of the target in each site, as (low, high) quantiles of the population distribution of y (0 <= low < high <= 1, with high - low >= 0.01). One pair applies to every site; a list of n_sites pairs gives one per site, e.g. [(0, 0.5), (0.5, 1)] for a site with the lower half of the targets and one with the upper half. Within its range, a site has the population distribution. None gives every site the whole population.

signaldict or None, optional (default None, i.e. {"linear": 2.0})

Generator of the base problem and its strength s, as {type: strength} with one type. f is standardized to mean 0 and SD 1 in the population, so that s is the SD of the explained part of y and the population R**2 = s**2 / (1 + s**2) (0.8 for s = 2; s = 0 gives a target unrelated to the features):

  • "linear": features ~ N(0, 1), f a linear combination of n_informative of them with random weights.

  • "friedman1": features ~ U(0, 1), f the Friedman #1 function 10 sin(pi x0 x1) + 20 (x2 - 0.5)**2 + 10 x3 + 5 x4 of the first five features (needs n_features >= 5), a nonlinear problem with interactions.

n_informativeint or None, optional (default None)

For "linear", the number of features that carry the signal (the first n_informative); None for all.

noise_strengthfloat or list of float, optional (default 0.1)

Standard deviation of the Gaussian noise added to the features, in reference-SD units, for all sites or per site.

site_effectdict or None, optional (default None, i.e. {"location": 3.0})

Types of EoS and their strength, as in make_multisite_classification() ("location", "scale", "variance", "nonlinear", "dropout", "combat").

site_effect_featuresint, float, sequence of int or None, optional (default None)

Features affected by the EoS: None for all, an int k for the first k, a float in (0, 1] for that fraction of the first features, or a sequence of indices.

site_effect_heterogeneityfloat, optional (default 0.0)

Variation of the EoS between the samples of a site: each sample’s site effect is multiplied by exp(h * z - h**2 / 2), z ~ N(0, 1) per sample.

covariateslist of Covariate or str, or None, optional (default None)

Covariate specifications (a Covariate or a preset name); their effects change the features, not the target.

site_namessequence or None, optional (default None)

Labels of the sites; None gives 0 to n_sites - 1.

as_framebool, optional (default False)

If True, X is a DataFrame, y a Series named "target" and sites a Series named "site".

return_ground_truthbool, optional (default False)

If True, also return a dict with the components of the data, all row-aligned with X. It has the keys of make_multisite_classification() (but "site_class_location"), and:

  • "target_signal": s * f(signal), the part of y explained by the signal (y - target_signal is e);

  • "target_coefficients": for "linear", the coefficients beta with target_signal = signal @ beta; None otherwise.

random_stateint, RandomState, Generator or None, optional (default 42)

The seed of the pseudo random number generator, or a RandomState or Generator, for reproducibility.

Returns:
Xnp.ndarray or DataFrame of shape (n_samples, n_features)

Simulated features.

ynp.ndarray or Series of shape (n_samples,)

Target.

sitesnp.ndarray or Series of shape (n_samples,)

Site labels (site_names, or 0 to n_sites - 1).

ground_truthdict

Only returned when return_ground_truth is True.

Raises:
ValueError

If a parameter has an invalid value.

TypeError

If a parameter has an invalid type.

See also

make_multisite_classification

The same model with class labels.

make_traveling_subjects

The same subjects measured in every site.

Examples

A site with the lower and one with the upper half of the targets (e.g. a young and an old cohort for brain-age prediction):

>>> X, y, sites = make_multisite_regression(target_range_per_site=[(0, 0.5), (0.5, 1)])
>>> X.shape, bool(y[sites == 0].max() <= y[sites == 1].min())
((1000, 10), True)
