PrettYharmonizeRegressor#

class uniharmony.prettyharmonize.PrettYharmonizeRegressor(harm_model: NeuroComBat | CovBat | ComBatGAM | None = None, base_model: BaseEstimator | None = None, stack_model: BaseEstimator | None = None, cv: int | Any = 5, fit_final_model: bool = True, return_harmonized_data: bool = False, n_jobs: int | None = None, random_state: int | None = None, regression_points: int | ArrayLike | None = None, regression_search: bool = False, regression_search_tol: float = 0.0, regression_search_max_iter: int = 20)#

Leakage-free ComBat harmonization for regression (PrettYharmonize).

Every sample is harmonized once per regression point (pretended target values spread over the training range). A base model scores each pretended version and a stack model, trained on out-of-fold scores, predicts the target [R3b9c478bda99-1]. The target of a predicted sample is never used.

Parameters:
harm_modelNeuroComBat, CovBat, ComBatGAM or None, optional (default None)

Unfitted ComBat-based harmonization model with its parameters set. None means NeuroComBat. The target is preserved as a continuous covariate (linear effect), or as smooth covariate (non-linear effect) with ComBatGAM unless additional_covariates already has a smooth covariate.

base_modelestimator or None, optional (default None)

Regressor fitted on the harmonized data. None means Pipeline([("scaler", StandardScaler()), ("ridge", RidgeCV(alphas=np.logspace(-3, 3, 13)))]): ComBat returns data in the original feature units, while the ridge penalty assumes comparable feature scales.

stack_modelestimator or None, optional (default None)

Regressor mapping the score matrix to the target. None means RidgeCV(alphas=np.logspace(-3, 3, 13)).

cvint, cross-validation splitter or iterable, optional (default 5)

Inner cross-validation. An int is the number of folds of a shuffled StratifiedKFold stratified by site (see PrettYharmonizeClassifier).

fit_final_modelbool, optional (default True)

If True, refit harm_model on all the training data and base_model on the out-of-fold harmonized training data. If False, average the score matrices of the inner-fold models to predict.

return_harmonized_databool, optional (default False)

If True, store the out-of-fold harmonized training data in harmonized_data_.

n_jobsint or None, optional (default None)

Number of inner folds fitted in parallel.

random_stateint or None, optional (default None)

Seed of the inner fold shuffling (used when cv is an int).

regression_pointsint, array-like or None, optional (default None)

Pretended targets. None means 10 points and an int k means k points, evenly spaced between the minimum and maximum training target.

regression_searchbool, optional (default False)

Instead of fixed points, search for each sample a self-consistent target t (base_model(harmonize(x, t)) ≈ t) by interval halving between the minimum and maximum training target (vectorized over samples). The score matrix then has a single column.

regression_search_tolfloat, optional (default 0.0)

Stop the search for a sample when |t - prediction| is below this value.

regression_search_max_iterint, optional (default 20)

Maximum number of interval halvings.

Attributes:
regression_points_ndarray

Pretended targets used.

y_min_, y_max_float

Range of the training target.

sites_, n_features_in_, score_matrix_, stack_model_, harm_model_, base_model_, fold_harm_models_, fold_base_models_, harmonized_data_

See PrettYharmonizeClassifier.

fit(X: ArrayLike, y: ArrayLike, sites: ArrayLike, additional_covariates: Mapping[str, ArrayLike] | None = None) → BasePrettYharmonize#

Fit the harmonization, base and stack models.

Parameters:
Xarray-like, shape (n_samples, n_features)

The training input samples.

yarray-like, shape (n_samples,)

The training target. It is always preserved by harm_model.

sitesarray-like, shape (n_samples,)

Sites.

additional_covariatesdict or None, optional (default None)

Other covariates preserved by harm_model, keyed by its covariate argument, e.g., {"categorical_covariates": sex, "continuous_covariates": age} or {"smooth_covariates": age} (ComBatGAM). Each value has one row per sample. They must be known for the data to predict too.

Returns:
object

The fitted estimator.

fit_transform(X: ArrayLike, y: ArrayLike, sites: ArrayLike, additional_covariates: Mapping[str, ArrayLike] | None = None) → NDArray#

Fit the model and return the out-of-fold harmonized training data.

Each training sample is harmonized with its true target (legitimate for training data) by the harmonization model of the inner fold where it was a validation sample. This differs from transform(), which harmonizes new data with their predicted target.

Parameters:
X, y, sites, additional_covariates

See fit().

Returns:
array, shape (n_samples, n_features)

The out-of-fold harmonized training data.
