`IntraSiteInterpolation` now caps interpolation by default and under-samples the remaining imbalance (set `max_amplification=None` for the previous pure over-sampling). Covariates now only restrict which samples are interpolated (and under-sampled) together and preserve the covariate distribution of each class and site, instead of balancing classes inside every stratum; `global_max` with covariates no longer fills every stratum up to the global maximum. A class missing from a site now raises an error (a regression bin missing from a site warns). Each site and stratum gets its own random stream, and the constructor parameters are no longer modified by `fit_resample`.
