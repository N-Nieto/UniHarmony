Change the site effects of `uniharmony.datasets.make_multisite_classification`: `site_effect_type="scale"` (and `"location+scale"`) now multiplies the deviations from the global mean by a per-feature factor exp(U(-0.1 s, 0.1 s)) instead of multiplying the features by U(0, 0.1 s), which shrank them 6–8 times towards 0 at the default strength; `site_effect_homogeneous=False` now varies each sample's effect around its site's effect instead of drawing it independently of the site, which gave every site the same mean. Because the sampling was fixed, the same `random_state` gives different data than in 0.0.4. Per-site messages are now logged at debug level.
