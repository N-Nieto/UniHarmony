Static typing of the public API (Pylance / pyright with the bundled scikit-learn stubs): `set_output` of the harmonizers (`NeuroComBat`, `ComBatGAM`, `CovBat`, `OptimalTransportDomainAdaptation`, `BARTharm`) is annotated to return `Self` instead of `BaseEstimator`, so `NeuroComBat(...).set_output(transform="pandas").fit_transform(df)` is no longer flagged; `fit` returns `Self`; `n_features_in_` and `feature_names_in_` are declared for type checkers; `transform` / `fit_transform` / `fit_resample` return `uniharmony._data.TransformOutput` (an array or a DataFrame, depending on `set_output` and the input).
