Add `uniharmony.datasets.make_multisite_regression`, the regression counterpart of `make_multisite_classification` with the same covariates, noise, site effects and ground truth. The target is `y = s f(X) + e`, with `f` linear or the nonlinear Friedman #1 function, standardized so that the population R² is s²/(1+s²). `target_range_per_site` gives each site a range of the population target (as quantiles, e.g. a young and an old cohort), so that the sites differ through the target as in real studies; the site effect never changes the target.
