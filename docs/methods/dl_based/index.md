# 🧠 Deep learning based

Deep learning methods harmonize the **images** themselves, rather than features
extracted from them. They require the optional PyTorch dependency:

```console
pip install uniharmony[dl]
```

For GPU training, install the PyTorch build for your CUDA version first, following
<https://pytorch.org/get-started/locally/>.
